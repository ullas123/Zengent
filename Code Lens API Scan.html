Installation Steps

  1. Install Python 3.9+ (skip if already installed)

    Download from python.org or use Homebrew:

    brew install python

  2. Install Graphviz

    brew install graphviz

  3. Install Git (usually pre-installed on Mac)

    git --version

    If missing, run: brew install git

  4. Unzip the project and open a terminal inside the folder

    cd code_lens

  5. Install Python packages

    pip3 install -r requirements.txt

  6. Run the app

    streamlit run app.py --server.port 5000
    ✅ Browser opens automatically at http://localhost:5000
    💡 Or just double-click start.sh from Finder.

  1. Install Python 3.9+

    Download from python.org.

    ⚠️ During install, check "Add Python to PATH" before clicking Install.

  2. Install Graphviz

    Download the installer from graphviz.org.

    ⚠️ During install, select "Add Graphviz to system PATH".

  3. Install Git

    Download from git-scm.com and install with defaults.

  4. Unzip the project, then open Command Prompt inside the folder:

    cd code_lens

  5. Install Python packages

    pip install -r requirements.txt

  6. Run the app

    streamlit run app.py --server.port 5000
    ✅ Browser opens automatically at http://localhost:5000
    💡 Or just double-click start.bat in the project folder.
