Installation Steps

1

Install Python 3.9+

Download from python.org/downloads or use Homebrew:

brew install python

Verify:

python3 --version
2

Install Graphviz (system library)

brew install graphviz
3

Place the app files

Unzip the downloaded code_lens_Data.zip into a folder, e.g. ~/code-lens/

4

Install Python packages

cd ~/code-lens
pip3 install streamlit pandas openpyxl networkx graphviz sqlparse pyyaml
5

Run the app

streamlit run app.py --server.port 5000

Then open http://localhost:5000 in your browser.

1

Install Python 3.9+

Download from python.org/downloads. During install, check "Add Python to PATH".

Verify in Command Prompt:

python --version
2

Install Graphviz (system library)

Option A – Winget:

winget install graphviz

Option B – download installer from graphviz.org/download and add to PATH.

3

Place the app files

Unzip code_lens_Data.zip into a folder, e.g. C:\code-lens\

4

Install Python packages

Open Command Prompt, navigate to your folder:

cd C:\code-lens
pip install streamlit pandas openpyxl networkx graphviz sqlparse pyyaml
5

Run the app

streamlit run app.py --server.port 5000

Then open http://localhost:5000 in your browser.

💡 If streamlit is not recognised after install, try restarting Command Prompt or run via python -m streamlit run app.py
