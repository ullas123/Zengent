Installation Steps
1
Clone the repository
bash
git clone https://github.com/your-org/nucleus-2.0.git
cd nucleus-2.0
2
Install Node.js packages
bash
npm install
3
Install Python packages
bash
pip3 install openpyxl numpy graphviz
4
Set up environment variables
Create a .env file in the project root and add your API keys:
.env
ANTHROPIC_API_KEY=sk-ant-...       # Primary AI (recommended)
OPENAI_API_KEY=sk-...              # Fallback AI (optional)
DATABASE_URL=postgresql://...       # Optional — skip for in-memory
5
Start the app
bash
npm run dev
Open http://localhost:5000 in your browser.
