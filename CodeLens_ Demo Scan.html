💻 Installation Steps

1

Check Python version

Open Terminal and confirm Python 3.11+ is installed:

python3 --version
Tip: If not installed, download from python.org or use Homebrew: brew install python
2

Extract the project files

Unzip CodeLens_Ver1.zip to a folder, then navigate into it:

cd ~/Downloads/CodeLens
3

Install dependencies

pip3 install -r requirements.txt
One-time step. Installs Streamlit, Plotly, pandas, FuzzyWuzzy and all other libraries.
4

Run the app

Option A — use the launch script:

bash run.sh

Option B — run directly:

streamlit run app.py --server.port 5000
5

Open in browser

Navigate to:

http://localhost:5000
